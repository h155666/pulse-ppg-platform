# 人体脉搏波信号生成与特征分析虚拟仿真平台（课题 5-4）

> 广东轻工职业技术大学 2024 级大数据专业 · 毕业设计
> 课题：**5-4 基于 Streamlit 的脉搏波信号生成与特征分析网页端平台设计**
> 技术栈：**Streamlit + SciPy + NumPy + Matplotlib + PyWavelets**（纯 Python，零前端代码，全程 CPU）

---

## 1. 这个平台做了什么

一个 `streamlit run app.py` 就能打开的网页端平台，覆盖脉搏波
**「生成 → 加噪 → 去噪 → 特征检测 → 形态学分析 → 指标评价 → 结果导出」** 的完整闭环，
并在 **17835 条真实仿真记录**（`raw_p11_ppg_sim_signal.csv`，48 列）上完成数据治理与群体分析。

### 1.1 为什么是"自生成 + 真实数据集"双数据源

| 数据源 | 有没有真值 | 负责什么 |
|---|---|---|
| 平台自生成（自适应高斯脉冲串） | ✅ 有 | **定量**：SNR、ΔSNR、RMSE、主波命中率 |
| raw_p11 仿真数据集 17835 条 | ❌ 没有 | **统计与外推**：字段治理、受试者/模型差异、算法适用性 |

真实记录没有干净波形，算不了 RMSE 与命中率（大方向背景 3.3 / 5-3 背景 Q13），
所以定量指标必须建立在有真值的自生成信号上；真实记录则用来证明结论具有外推性。

### 1.2 与项目指导书的关系

《大数据开发项目指导书》要求 Hadoop/Hive/Spark + Flask+Vue，
但课题 5-4 的指导文件**硬性规定技术栈为 Streamlit + scipy + matplotlib**，且 Hive/HDFS
在 Windows 单机本科环境不可部署。本平台的取舍：

- **外壳听 5-4**：展示层 100% Streamlit，零 HTML/CSS/JS；
- **数据听指导书**：数据源是 raw_p11 的 17835 条记录；
- **算法听 5-3 / 大方向**：`pulse_core.py` 即 5.3 的算法内核；
- **Spark 段等价降级**：清洗 / 标准化 / 特征工程用 pandas 列向量化实现，
  口径与 Spark 一致，实测治理耗时约 0.4 s（页面 KPI 直接显示），作为工程佐证。

详见 `docs/设计思路.md`。

## 2. 快速开始

### 方式 A：双击 `启动平台.bat`（推荐，零配置）

项目根目录的 `启动平台.bat` 会使用**已经装好所有依赖的虚拟环境**直接启动，
双击即可，浏览器自动打开 `http://localhost:8502`。

### 方式 B：命令行（不污染系统 Python）

```bash
cd pulse_ppg_streamlit
"C:\Users\15778\.workbuddy\binaries\python\envs\pulse\Scripts\python.exe" -m streamlit run app.py --server.port 8502
```

### 方式 C：自己重新装环境

```bash
cd pulse_ppg_streamlit
pip install -r requirements.txt
streamlit run app.py
```

> ⚠️ **注意**：**不要用 Python 3.14 装环境**。PyWavelets 1.8.0 目前只为
> Python ≤3.13 提供预编译包（wheel），在 3.14 上 pip 会退回到源码编译
> （需要 C/C++ 编译器），会报 `metadata-generation-failed`。
> 自行安装请用 **Python 3.11 / 3.12 / 3.13**；或者直接用方式 A / B 的现成环境。

### 方式 D：后台常驻（答辩演示 / 长期挂着）

```bat
run_server.bat            :: 启动服务（默认 8502），日志写入 logs\server.log
run_server.bat 8600       :: 指定端口
stop_server.bat           :: 停止（按端口精确定位进程，不会误杀别的 python）
install_autostart.bat     :: 可选：加进「启动」文件夹，登录后自动拉起
uninstall_autostart.bat   :: 取消上面的开机自启
```

更彻底的做法是交给 **Windows 任务计划程序**（本机已配置好，任务名 `PPGPlatform`）：
登录即启动、无运行时长上限、异常退出自动重试，且独立于任何终端窗口。
对应命令：

```bat
schtasks /query  /tn PPGPlatform        :: 查看状态
schtasks /run    /tn PPGPlatform        :: 立即启动
schtasks /end    /tn PPGPlatform        :: 停止
schtasks /delete /tn PPGPlatform /f     :: 取消常驻
```

任务的实际入口是 `%LOCALAPPDATA%\PPGPlatform\start_hidden.vbs`（隐藏窗口调用
`run_server.bat`），所以不会有黑色控制台窗口常驻在任务栏。

浏览器会自动打开 `http://localhost:8501`（或 8502）。

数据文件默认查找顺序：
侧边栏显式路径 → 环境变量 `PPG_DATA` → `项目/data/raw_p11_ppg_sim_signal.csv`
→ 学校测试数据目录。也可以直接在侧边栏上传 CSV。

## 5. 算法能力

**信号生成**：自适应高斯脉冲串。三波位置用**相对相位 φₖ**与**相对脉宽 wₖ**表达
（`μₖ = φₖ·T, σₖ = wₖ·T`），修正了教材代码在 HR>100 bpm 时潮波/重搏波被 `t % T`
折叠失真的缺陷；并可由生成参数直接反推真值峰位置，无需人工标注。

**噪声模型**：高斯白噪 / 基线漂移 / 工频干扰 / 运动伪影 / 复合噪声（与数据集
`noise_type` 字段口径一致）。

**去噪方法（8 种）**

| 方法 | 关键参数 | 对应数据集字段 |
|---|---|---|
| 无（基线） | — | 未处理（3198 条） |
| 低通滤波 | 截止频率、阶数（`filtfilt` 零相位） | — |
| 小波阈值去噪 | 小波基 db4/sym8/coif3/db6、层数（自适应上限）、阈值系数、软/硬 | 小波阈值去噪（3863 条） |
| EMD 经验模态分解 | 最大 IMF 数、丢弃高频 IMF 数（**自实现 sift，无 PyEMD 依赖**） | EMD经验模态分解（2162 条） |
| Savitzky-Golay 滤波 | 窗口长度、多项式阶数 | Savitzky-Golay滤波（2443 条） |
| 0.5–8 Hz 带通 | 上/下截止、阶数 | 0.5-8Hz带通滤波（2160 条） |
| 中值滤波 | 核大小 | 中值滤波（758 条） |
| 自适应陷波 + 低通 | 陷波频率、Q、截止频率 | 自适应陷波滤波（1097 条） |

> VMD 变分模态分解（数据集 2114 条）**未实现**，仅作统计展示，列入展望 —— 如实说明优于伪造结果。

**特征与指标**：主波 / 潮波 / 重搏波 / 重搏切迹；脉宽、上升时间、AIx、RI、SI、PI、K 值、dp/dt_max；
SNR、ΔSNR、RMSE、主波命中率（容差匹配）、单次处理耗时。

## 6. 数据治理

| 字段 | 原始口径 | 归一后 | 说明 |
|---|---|---|---|
| gender | 20 种（男/Male/f/1/先生…） | 3–4 类 | 男/女/其他 |
| sim_status | 8 种（成功/success/OK/重算…） | 4 类 | 成功/部分收敛/失败重算/超时中断 |
| noise_level | 13 种（中/LOW/2/轻度…） | 5 类 | 无/低/中/高/极高 |
| export_format | 11 种（CSV/csv;utf8/.CSV/excel…） | 7 类 | CSV/JSON/TXT/MAT/HDF5/DAT/EXCEL |
| operator_role | 9 种（含"（旧）"后缀） | 4 类 | 本科生/研究生/指导教师/实验员 |

**异常值（指导书 3.4 对账）**：`point_count` 178 条负值 + 97 条 2^30 量级哨兵（按 fs×时长 重建）、
`dbp_mmhg` 21 条负值、`augmentation_index` 2642 条负值（max 99786）、`snr_db` 66 条负值 + 999.99 哨兵、
`cardiac_output`/`pulse_amplitude`/`dpdt_max` 的 ~1e5 离群。治理策略可在页面 ④ 切换（标记/置缺失/全局中位数/分组中位数）。

**脏串解析**：`to_number()` 可处理 `"0.39 s"`（→390 ms）、`"333ms"`、`"156/98"`（→156）、`"45岁"`、`"未识别"` 等写法。

## 7. 一个值得写进论文的发现

在页面 ⑤ 做**口径可比性分析**时发现：

- **脉宽**：波形重算值（半高宽）与库内字段**强相关（r ≈ 0.93）**，但存在系统性尺度偏差
  （比值 ≈ 0.76），说明二者口径不同，库内更接近"低电平宽度"；
- **上升时间 / AIx / PI / dp/dt_max**：与波形重算值**几乎不相关**，
  说明这些字段是独立仿真生成的，**不能当作波形真值**使用。

这正是指导书 3.4 ⑤「形态学特征计算口径多样」的实证，
也是本平台坚持"定量指标只在有真值的自生成信号上计算"的原因。

## 9. 可复现性

- 所有随机过程统一走 `np.random.default_rng(seed)`，默认种子 **42**；
- 批量实验支持 1–10 个种子取平均（大方向背景 5.2「多次重复」）；
- 导出的 CSV 与页面显示数值完全一致，可直接作为论文表格数据源。
