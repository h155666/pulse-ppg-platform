### 1.2 材料之间的两处冲突（这是本题的关键）

**冲突一：5-4 只字未提大数据集，指导书却给了 17835 条 × 48 列。**
- 5-4 背景 3.1 只要求"仿真数据（自生成，主用）+ 上传 PhysioNet CSV 作对照"；
- 指导书 3.2 明确"原始数据共 17837 行 48 列，剔除 1 行字段说明记录，有效 17835 条"，并按 8 类受试者、6 种生成模型给出精确分布。

**冲突二：指导书要求 Hadoop + Hive + Spark + Flask + Vue，与 H1 直接矛盾。**
- 指导书 4.1 规定"存储层 HDFS/Hive、计算层 Spark、服务层 Flask、展示层 Vue+ECharts"；
- 5-4 指导 0.5 明令"不要把前端改成 Vue（那是 5.2）""技术栈固定为 Streamlit"。

### 1.3 冲突的裁决原则

README 3.2 规定阅读顺序是"大方向背景 → 课题指导 → 课题背景"，**课题文件优先于通用指导书**；且 README 4 节把 5.4 明确定位为 ★ 入门级、技术栈固定。因此：

> **外壳听 5-4 的（Streamlit），数据听指导书的（raw_p11 数据集），算法听 5-3/大方向的（高斯脉冲串 + 三类去噪）。**

指导书里 Hadoop/Hive/Spark 的部分，属于"26 个通用项目模板"的大数据话术，无法也不应在 5-4 的约束下实现（Hive/HDFS 在 Windows 单机本科环境不可部署，pyspark 本地模式启动慢、答辩易卡，违背 5-4 指导 10.5"演示不能卡"的要求）。正确做法是**在论文里显式声明等价降级**：Spark 负责的"清洗—标准化—特征工程"三段，本平台用 pandas 的**列向量化 + 分块（chunk）**在同一份数据上等价完成，并给出处理耗时对比作为工程佐证。这反而是答辩的加分项（能讲清为什么不用 Spark）。

### 思路 A · 纯仿真轻量 demo（严格照抄 5-4 背景 4.2 骨架）

只实现"高斯脉冲串生成 → 加噪 → 3 种去噪 → 指标卡"，上传 CSV 作为摆设。

| 维度 | 评价 |
|---|---|

| 与指导书贴合度 | ✗ 17835 条数据集完全没用上 |

### 思路 B · Streamlit 外壳 + raw_p11 数据集中台（**选定**）

保留 5-4 全部硬约束，把数据源升级为指导书的 raw_p11 数据集，用 pandas 在单机完成指导书的"采集—清洗—特征工程—分析—评估—可视化"六段。同时**保留高斯脉冲串自生成模块**作为"有真值"的定量基线。

| 维度 | 评价 |
|---|---|
| 贴合 H1~H3 | ★★★★★（依然 100% Streamlit + scipy + matplotlib，零前端代码） |
| 工作量 | 4~5 周（对应 指导 7~12 周） |
| 与指导书贴合度 | ★★★★（12 个任务落地 10 个，仅 HDFS/Hive 单机化） |
| 论文第 4 章 | 双证据：仿真真值定量（RMSE/命中率）+ 17835 条真实记录定性分布 |
| 难度 | 从 ★ 提升到 ★★★，README 4 节"★★★ 中等"档 |

**为什么必须同时保留自生成模块？**
因为 raw_p11 数据集**没有干净真值**（`ppg_wave` 已经是带噪序列），无法计算 RMSE 和特征点命中率。大方向背景 3.3 与 5-3 背景 Q13 都强调"仿真为主、真实仅作佐证"。所以平台设计成**双数据源**：

- 自生成（有真值）→ 负责**定量**：SNR 增益、RMSE、命中率、方法排序
- raw_p11（无真值但有 1.7 万条统计规律）→ 负责**定性 + 统计**：字段治理、受试者/模型差异、形态学特征分布、算法在不同噪声类型上的适用性

这正是本方案相对于思路 A 的核心增量，也是论文的第二个创新点。

### 思路 C · Streamlit + 本地 PySpark / Hive

| 维度 | 评价 |
|---|---|
| 贴合 H1 | ✗ 引入 pyspark 违背"技术栈固定" |
| 可行性 | ✗ Hive/HDFS 在 Windows 单机不可部署；pyspark 需 JVM，8GB 笔记本冷启动 20s+ |
| 风险 | 答辩现场卡顿（5-4 指导 10.5 明确预警） |

**裁决：选 B。**

### 3.4 算法层详细设计（pulse_core.py）

#### 3.4.1 信号生成 —— 改进的自适应高斯脉冲串

大方向背景 7 节的原始代码有个**真实缺陷**：
```python
mus=(0.18, 0.40, 0.58)   # 绝对秒位置
tp = t % T                # T = 60/hr
```
当 HR=180 时 T=0.333 s，而 μ₂=0.40、μ₃=0.58 **已经超出一个周期**，潮波与重搏波会被 `t % T` 折叠到错误位置，波形完全失真。这正是大方向背景 6 节"常见坑 1：采样率与周期对不上"的延伸。

**本方案的修正**：把三波位置改为**相对相位** φₖ∈(0,1) 与**相对脉宽** wₖ，实际参数随周期自适应：
```
μₖ = φₖ · T ,   σₖ = wₖ · T ,   T = 60 / HR
s(t) = Σ Aₖ · exp( −(t' − μₖ)² / (2σₖ²) ) ,  t' = t mod T
```
默认值取 φ=(0.20, 0.42, 0.62)、w=(0.055, 0.055, 0.070)、A=(1.00, 0.38, 0.24)。
在 HR=75（T=0.8 s）时退化为 μ=(0.16, 0.336, 0.496)、σ=(0.044, 0.044, 0.056)，与指导书默认 `mus=(0.18,0.40,0.58)`/`sigmas=(0.05,0.04,0.05)` 量级一致 —— **既修了 bug，又不偏离教材**，可直接写进论文 3.2 节作为"模型改进点 1"。

同时提供 `return_truth=True` 直接返回真值峰索引（`round(φₖ·T·fs)` 加上周期偏移），**无需事后去猜真值**，命中率计算因此更严谨。

#### 3.4.2 噪声模型（对应指导书 `noise_type` 的 6 类）

```
x_noisy = x + n_white + n_drift + n_mains + n_motion
  n_white  : 高斯白噪，功率由目标 SNR 反解  P_n = P_s / 10^(SNR/10)
  n_drift  : 低频正弦/随机游走基线漂移（0.1~0.5 Hz）
  n_mains  : 50 Hz 工频干扰（指导书"工频干扰"2486 条）
  n_motion : 大幅度低频突发（运动伪影，用低频调制 + 稀疏脉冲）
```
每种分量可单独开关与调幅，使"复合噪声"场景可复现。

#### 3.4.3 八种去噪方法（对应指导书 `denoise_algo` 的 7 类 + 无）

| 方法 | 实现 | 关键参数 | 对应数据集字段 |
|---|---|---|---|
| 无 | 直通（基线） | — | 未处理（3198 条） |
| 低通 | `butter` + **`filtfilt`（零相位）** | fc 5~25 Hz, order 2~6 | — |
| 小波 | `wavedec`→软/硬阈值→`waverec`，**截断对齐** | db4/sym8/coif3, level 自适应, thr 0.01~0.3 | 小波阈值去噪（3863 条） |
| EMD | **自实现 sift 迭代**（不依赖 PyEMD） | max_imf, drop 前 k 个 | EMD经验模态分解（2162 条） |
| Savitzky-Golay | `savgol_filter` | window(奇数), polyorder | Savitzky-Golay滤波（2443 条） |
| 带通 0.5–8 Hz | `butter` bandpass + `filtfilt` | lo, hi | 0.5-8Hz带通滤波（2160 条） |
| 中值 | `medfilt` | kernel（奇数） | 中值滤波（758 条） |
| 陷波+低通 | `iirnotch` 50 Hz + 低通 | f0, Q, fc | 自适应陷波滤波（1097 条） |

> VMD 变分模态分解（数据集 2114 条）未实现，列入"展望"——**如实说明优于伪造**，符合指导 8.4"不得编造结论"。

三个必须规避的坑（大方向背景 6 / 5-3 背景 6）：
- **坑 3 相位失真**：一律用 `filtfilt`，绝不用 `lfilter`；
- **坑 2 小波层数**：`level = min(设定值, pywt.dwt_max_level(len(x), wname))`，且 `waverec` 结果 `[:len(x)]` 截断；
- **Q2 长度对齐**：所有方法统一 `_fix_len()` 保证返回同长度（指导 2.2 验收标准）。

#### 3.4.4 三波 + 切迹检测（对应 指导 3.3、背景 2.6）

```
1) 主波：find_peaks(x, distance=⌊0.7·T·fs⌋, prominence=0.25·(max-min))
2) 每个主波 p 之后开窗口 (p, p + 0.75·T·fs)：
     候选峰 = find_peaks(段, distance=⌊0.05·T·fs⌋, prominence=0.02·(max-min))
3) 窗口内按幅值取前 2：位置靠前 → 潮波，靠后 → 重搏波
4) 切迹：在主波与潮波之间找 argmin（局部极小）
5) 后处理："每周期至少一个主波"约束（5-3 背景 Q4），缺失周期用相邻周期主波间距插补
```
返回结构化 `FeatureSet`：主波/潮波/重搏波/切迹的 (索引, 时刻ms, 幅值) 及每周期一行。

#### 3.4.5 形态学特征（对应指导书任务 5）

| 特征 | 定义 |
|---|---|
| 主波幅值 A_sys | 主波峰值（归一化后） |
| 脉宽 PW | 半高宽（50% 幅值处两交点时间差，ms） |
| 上升时间 RT | 10% → 90% 幅值的时间差（ms） |
| 重搏切迹时刻 t_dn | 主波后的局部极小（ms） |
| 增强指数 AIx | (A_dic − A_dn) / (A_sys − A_dn) × 100% |
| 硬化指数 SI | 身高 / PTT（m/s），PTT 用主波间隔近似 |
| 灌注指数 PI | (AC 幅值 / DC 基线) × 100% |
| dp/dt_max | 一阶差分最大值 |
| K 值 | (mean − min)/(max − min) 的形态系数 |
| 心率 HR_est | 60000 / 主波间期中位数 |

#### 3.4.6 评价指标（大方向背景 3.4）

```
SNR(clean, y)   = 10·log10( Σclean² / Σ(clean−y)² )
ΔSNR            = SNR(clean, denoised) − SNR(clean, noisy)      # 去噪增益（5-3 Q10）
RMSE(clean, y)  = sqrt(mean((clean−y)²))
命中率          = 命中真值峰数 / 真值峰数，容差 ±tol ms（默认 50 ms）
漏检率          = 1 − 命中率
耗时            = time.perf_counter() 差值（ms）
```

## 第七部分：本方案的三个可写进论文的点

1. **模型改进**：把高斯脉冲串的三波位置由"绝对秒"改为"相对相位 φₖ/相对脉宽 wₖ"，修正了 HR>100 时潮波/重搏波被 `t % T` 折叠失真的缺陷，并可由生成参数直接反推真值峰位置，使命中率计算无需人工标注。
2. **工程决策**：在 5-4 的 Streamlit 硬约束下，用 pandas 单机列向量化等价替代指导书的 Spark/Hive 三层，并给出处理耗时与口径一致性证据。
3. **双证据评测**：仿真（有真值，算 RMSE/命中率）+ 17835 条仿真记录（无真值，算群体分布与算法适用性），避免"只有仿真空对空"或"只有真实数据无定量"的两种单薄。
